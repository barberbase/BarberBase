# UNIT: O5 — media routes on openapi.yaml

REPO: barberbase-core
BRANCH: from clean main after O3, clean working tree

## Context

M2 shipped the full R2 media pipeline — presign, commit, archive, reaper,
purge handler — as repository and domain layers with no HTTP surface,
because openapi.yaml was frozen. This unit adds the four routes and wires
them.

First unit to add PATHS rather than fields. Per the API1 ruling, new routes
use the GENERATED STRUCTS, not hand-built map literals. The compiler
enforces the contract on new surface; the existing 327 hand-built responses
are not retrofitted.

## Routes

| Method + path | Backed by |
|---|---|
| POST /v1/admin/media/presign | media.Service.Presign |
| POST /v1/admin/media/{id}/commit | media.Service.Commit |
| DELETE /v1/admin/media/{id} | media.Service.Archive |
| GET /v1/admin/media | ListAssets (new, see below) |

All StaffJWT, role owner/manager. tenant_id and location_id from JWT
claims, never the body (Law 11).

## New repository method

GET /v1/admin/media needs ListAssets, which M2 did not build. O5 is not
pure wiring. Filters: purpose, service_variant_id, staff_member_id. Scoped
to the JWT's tenant and location. Returns ready and pending; archived only
when explicitly requested. State the default.

## $ref constraint — O2 confirmed this empirically

oapi-codegen strips `nullable` and sibling `description` when they sit
beside a `$ref`. Do NOT put either beside a $ref on any media field. Inline
the type or wrap in allOf. Several media fields are nullable UUIDs
(service_variant_id, staff_member_id), so this will arise — handle it and
report which approach you used.

## Public read is not a route

Public image reads are R2_MEDIA_PUBLIC_BASE_URL + r2_key, served by
Cloudflare, no API route. The spec documents the URL construction in a
description; it does not add a path.
